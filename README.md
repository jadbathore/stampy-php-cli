# Stampy/php-cli

Une plugin permettant de facilité l'utilisation de l'invité de commande en php dans sont projet avec de nombreuse utilsation 

## le principe 

Aprés l'installation un fichier bash permettant l'interaction avec le terminal en php sera crée.Il y aurai également un dossier /console/controller dans le namespace de votre choix. Grâce a cela vous auriez une manier propre et organisé d'apeler vos script depuis votre projet php.

## installation

### via composer

```
    composer require stampy/php-cli
```

Par la suite composer va vous demander dans quelle namespace vous vouliez mettre votre console choisiez l'un des elements de la liste déroulante.
